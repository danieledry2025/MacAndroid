# MacAndroid

העברת קבצים בין טלפון אנדרואיד ל-Mac **בכבל USB**, עם ממשק שמרגיש כמו סייר הקבצים של Windows:
מחברים את הטלפון, נכנסים אליו כמו לתיקייה, ו**רואים את הקבצים** (כולל תמונות ממוזערות של תמונות וסרטונים) לפני שמעתיקים.

מבוסס על הרעיונות של [OpenMTP](https://github.com/ganeshrvel/openmtp) ו-MacDroid, אבל עם דגש על פשטות ותצוגה.

## מה יש

- **זיהוי אוטומטי**: מחברים את הטלפון והאפליקציה נכנסת אליו לבד (כמו כונן ב"מחשב זה").
- **תצוגת קבצים אמיתית**: סמלים גדולים עם תמונות ממוזערות, או תצוגת פרטים (שם, תאריך, סוג, גודל) עם מיון.
- **צפייה בתמונות ובסרטונים** בתוך האפליקציה: רווח או לחיצה כפולה, חיצים למעבר בין תמונות.
- **העתקה בכל דרך שמכירים**:
  - כפתור "העתק למחשב" / "העתק לטלפון"
  - ⌘C ו-⌘V בין הטלפון לתיקיות ב-Mac (גם קבצים שהועתקו ב-Finder אפשר להדביק ישר לטלפון)
  - גרירה מה-Finder לתוך החלון, או גרירה מהטלפון לתיקייה בסרגל הצד
- **מסך מפוצל**: הטלפון בצד אחד והמחשב בצד השני. גוררים מצד לצד, או בוחרים ולוחצים F5 (או הכפתור הכחול) כדי להעתיק לצד השני.
- **גרירה ישירה למחשב**: גוררים קבצים מהאפליקציה ישר ל-Finder, לשולחן העבודה או לכל אפליקציה. קבצים שנבחרו בטלפון מוכנים ברקע, כך שהגרירה מתחילה מיד.
- **החדשים קודם**: ברירת המחדל היא מיון לפי תאריך, מהחדש לישן. אפשר להחליף לשם, גודל או סוג.
- **התקדמות העתקה** עם מהירות וזמן שנותר, אפשרות ביטול, וטיפול בקבצים קיימים (החלף / שמור את שניהם / דלג).
- תיקייה חדשה, שינוי שם (F2), מחיקה, חיפוש בתיקייה, קיצורי דרך למצלמה, צילומי מסך, הורדות ו-WhatsApp.
- תמיכה בכרטיס SD, ומצב כהה.

## איך זה עובד (ולמה בכבל זה מהיר)

האפליקציה מדברת עם הטלפון דרך **ADB** (הכלי הרשמי של Google), על כבל ה-USB.
זה יציב ומהיר יותר מ-MTP ב-Mac, שבו Android File Transfer ודומיו נוטים להיתקע.
ה-adb נארז בתוך האפליקציה, אין צורך להתקין שום דבר נוסף.

## הכנה חד פעמית בטלפון

1. **הגדרות ← אודות הטלפון** ← לחץ 7 פעמים על **מספר Build** (בסמסונג: אודות הטלפון ← מידע על התוכנה).
2. חזור להגדרות ← **אפשרויות מפתח** ← הפעל **ניפוי באגים ב-USB**.
3. חבר את הכבל, בחר בטלפון **העברת קבצים**, ובהודעה שקופצת סמן **"אפשר תמיד ממחשב זה"** ולחץ **אפשר**.

## התקנה

### מהגרסה הבנויה
בכל דחיפה לגיטהאב, GitHub Actions בונה קובץ DMG (לשבבי Apple ול-Intel).
נכנסים ללשונית **Actions** ← הריצה האחרונה ← מורידים את **MacAndroid-mac**.

האפליקציה לא חתומה בחתימת מפתח של Apple, ולכן בפתיחה הראשונה:
לחיצה ימנית על MacAndroid ← **פתח** ← **פתח**. אם macOS אומר שהיא "פגומה", הריצו בטרמינל:

```bash
xattr -cr /Applications/MacAndroid.app
```

### מקוד המקור
צריך Node.js 20 ומעלה.

```bash
npm install
npm run fetch-adb   # מוריד את adb הרשמי של Google לתיקיית vendor/
npm start
```

לבניית DMG בעצמכם: `npm run dist` (הקבצים יופיעו ב-`dist/`).

### לנסות בלי טלפון
```bash
npm run demo
```
מצב דמו מציג "טלפון" מדומה (תיקייה בשם `mock-phone`) כדי לראות את כל הממשק.

## קיצורי מקלדת

| פעולה | מקש |
|---|---|
| פתיחה | Enter או לחיצה כפולה |
| תצוגה מקדימה | רווח |
| העתק לצד השני (מסך מפוצל) | F5 |
| מעבר בין הצדדים | Tab |
| העתק / הדבק | ⌘C / ⌘V |
| בחר הכל | ⌘A |
| שינוי שם | F2 |
| מחיקה | ⌘⌫ או Delete |
| תיקייה חדשה | ⌘⇧N |
| אחורה / קדימה / למעלה | ⌘[ / ⌘] / ⌘↑ |
| חיפוש | ⌘F |
| רענון | ⌘R |

## מבנה הקוד

```
src/main/main.js       חלון, תפריטים ו-IPC
src/main/adb.js        זיהוי מכשירים ופעולות קבצים בטלפון (adbkit + adb)
src/main/local.js      פעולות קבצים ב-Mac
src/main/transfers.js  תור העתקות עם התקדמות, ביטול והתנגשויות
src/main/thumbs.js     תמונות ממוזערות (Quick Look ב-Mac) עם מטמון
src/main/mock.js       טלפון מדומה למצב דמו
src/renderer/          הממשק (HTML/CSS/JS, בעברית ומימין לשמאל)
```

בדיקות: `npm test`.
